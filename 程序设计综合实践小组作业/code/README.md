# 走迷宫游戏（C 语言 / 控制台字符画版）

程序设计综合实践 / 小组项目  作者：崔家腾（24115248）

## 模块清单

| 文件                  | 行数 | 内容                                                  |
| -------------------- | --- | ---------------------------------------------------- |
| `main.c`             | ~130 | 程序入口、主菜单、流程控制、模块调度                       |
| `maze.c` / `maze.h`  | ~90  | 迷宫数据结构 + 递归回溯生成                              |
| `dfs.c` / `dfs.h`    | ~70  | DFS 深度优先求解（递归）                                |
| `bfs.c` / `bfs.h`    | ~90  | BFS 广度优先求最短路径（数组模拟队列 + 父节点回溯）           |
| `render.c` / `render.h` | ~100 | 控制台字符画绘制（迷宫格、菜单、状态栏）              |
| `input.c` / `input.h`   | ~50  | 键盘输入（conio.h 方向键、回车、Esc、Q 等）          |

## 编译

只依赖 MinGW-w64 GCC 14.2.0（**不需要 EasyX**）。在 `code\` 目录下：

```bash
gcc *.c -o maze.exe
```

或带警告：

```bash
gcc -Wall -O2 *.c -o maze.exe
```

## 运行

```bash
.\maze.exe
```

## 操作

- 主菜单：上下方向键选择，回车确认，Q 退出
- 难度：小 11×11 / 中 21×21 / 大 31×31
- 手动玩：方向键移动，撞墙不动，到达 `E`（终点）游戏胜利，Esc 返回菜单
- 自动求解：进入后等待绘制完成，状态栏显示算法、扩展节点数、路径步数

## 迷宫字符约定（每格 2 字符宽，视觉接近正方形）

| 值  | 含义     | 显示    |
| --- | ------- | ------- |
| 0   | 通路     | `  ` (两空格) |
| 1   | 墙       | `##`    |
| 2   | 起点     | `S `    |
| 3   | 终点     | `E `    |
| 4   | 路径标记  | `. `    |
| 5   | 玩家     | `P `（手动玩时临时标记） |
